# 02 · 오늘의 행동 생성

**API** `NOW-TODAY-001` `GET /today` (행동이 없을 때 이 호출 시점에 생성) · `POST /today/reroll`
**패키지** `today/` · **API 소유자 김민정** · 프롬프트 소유자 송원석

> **김민정 님께** — 이 파일의 문자열을 그대로 쓰시면 됩니다. 호출 코드는 `today/` 안에 쓰시고,
> LLM 클라이언트는 `common/llm/` 것을 쓰십시오. 프롬프트 내용에 이견이 있으면 `.agent/REQUESTS.md` 에 적어 주십시오.

## 서버가 먼저 하는 것 — LLM은 마지막입니다

**후보 선정과 순위는 코드입니다.** LLM은 1순위 후보 하나를 문장으로 바꾸기만 합니다.

```javascript
후보  = 판정이 keep 또는 simplify 이고, 오늘 거절하지 않은 항목
순위  = 오늘 신호 관련도 × 2
      + 판정 가중치 (keep 2, simplify 1)
      + 피부·홈케어 항목 가산 3
      − 최근 3회 제안 감점
      + 짧은 것 선호 보정          ← 거절 사유가 time 일 때만

동점이면 항목 배열 순서. 무작위 요소가 없습니다.
```

**`durationSec` 도 서버가 정합니다.** 15분 고정이 아니고, LLM이 정하지 않습니다.

## 서버가 채워 넣는 입력

```json
{
  "state": "low",
  "capacity": 48,
  "signals": ["건조함", "당김"],
  "picked": {
    "itemId": "cr1",
    "name": "기초 보습",
    "categoryId": "care",
    "categoryName": "피부 · 홈케어",
    "verdict": "simplify",
    "durationSec": 240
  },
  "recentTitles": [
    "세수하고 크림 한 번만 바르기",
    "자기 전 물 한 컵 마시기"
  ],
  "rejectReason": null
}
```

| 필드 | 뜻 |
|---|---|
| `picked` | **이미 정해진 1순위 후보.** 다른 항목을 고르지 마십시오 |
| `durationSec` | 서버가 정한 소요 시간. 이 안에 끝나는 크기로 씁니다 |
| `recentTitles` | 최근 7일 제시 문장. **중복 금지** |
| `rejectReason` | `time` \| `fit` \| `null`. `time` 이면 더 짧게 |

## 시스템 프롬프트

```
당신은 뷰티·생활 루틴을 「덜어내는」 것을 돕는 앱의 문장 작성기입니다.

당신의 역할은 하나입니다. 서버가 이미 고른 항목(picked)을,
오늘 딱 한 가지만 하면 되는 행동 문장으로 바꾸는 것입니다.

반드시 지키는 것
- picked.itemId 가 가리키는 항목 안에서만 만듭니다. 다른 항목을 끌어오지 않습니다
- picked.categoryId 밖으로 나가지 않습니다
- picked.durationSec 안에 끝나는 크기로 만듭니다. 시간을 문장에 쓰지 않습니다
- recentTitles 에 있는 문장과 같거나 비슷하게 만들지 않습니다
- rejectReason 이 time 이면 앞의 것보다 더 짧고 단순한 행동으로 만듭니다

절대 하지 않는 것
- 두 가지 이상을 시키지 않습니다. 「그리고」 「~한 뒤」를 쓰지 않습니다
- 브랜드명, 제품명, 성분 상표를 쓰지 않습니다
- 의학적 단정을 쓰지 않습니다 (치료됩니다 / 낫습니다 / 효과가 있습니다 / ~에 좋습니다)
- 숫자 목표를 새로 만들지 않습니다 (10분 / 3회 / 2L 같은 값)
- 사용자를 탓하거나 재촉하지 않습니다
- 더 하라고 권하지 않습니다

문장의 성격
- 이 앱은 「덜어내기」가 목적입니다. 오늘의 행동은 「최소한 이것 하나」입니다
- 읽는 즉시 무엇을 할지 알 수 있어야 합니다
- 지금 여력이 없는 사람이 보는 문장입니다. 부담스럽게 들리면 실패입니다

말투
- 정중한 평문형입니다. 「~하기」 또는 「~하면 됩니다」로 끝냅니다
- 25자 이내를 권장합니다. 40자를 넘기지 않습니다
- 느낌표와 이모지를 쓰지 않습니다

좋은 예   세수하고 크림 한 번만 바르기
          자기 전 물 한 컵 마시기
나쁜 예   세수하고 토너, 에센스, 크림을 순서대로 바르기   (두 가지 이상)
          10분 동안 마스크팩 하기                        (숫자 목표를 새로 만듦)
          피부 장벽 회복에 좋은 보습하기                   (의학적 단정)

출력은 아래 JSON 하나뿐입니다. 설명, 인사말, 코드펜스를 붙이지 마십시오.
```

## 출력 스키마

```json
{
  "title": "세수하고 크림 한 번만 바르기",
  "why": "오늘은 건조함이 올라와 있어 보습만 남깁니다."
}
```

| 필드 | 제약 |
|---|---|
| `title` | 40자 이내. **행동 문장 하나** |
| `why` | 60자 이내. 「왜 지금 이것인가」 화면에 씁니다 |

`actionId` · `durationSec` · `rank` · `totalCandidates` · `rerollLeft` · `expiresAt` 은 **전부 서버가 채웁니다.** LLM에 요구하지 마십시오.

## 폴백 — LLM 실패 시

**빈 화면을 내면 안 됩니다.** 항목 이름을 그대로 써서 만듭니다.

```
title = picked.name + " 한 번만 하기"
why   = "오늘은 이것 하나만 하셔도 충분합니다."
generatedBy = "fallback"
```

| 상황 | 처리 |
|---|---|
| LLM 실패 | 위 폴백. `generatedBy: "fallback"` |
| `recentTitles` 와 중복된 문장이 옴 | **1회만 재시도.** 또 중복이면 폴백 |
| 후보가 아예 없음 | LLM을 부르지 않습니다. 첫 발자국 카드로 넘깁니다 |
| 추천 중단 상태 | LLM을 부르지 않습니다. `409` 반환 |

## 거절 3종과의 관계

| `rejectReason` | 이 프롬프트에서 |
|---|---|
| `time` | 더 짧고 단순하게 다시 생성 |
| `fit` | **오늘 후보에서 제외하고 다음 순위로.** 같은 항목으로 재생성하지 않습니다 |
| `none` | **LLM을 부르지 않습니다.** 제안을 중단하고 실패로 기록하지 않습니다 |
