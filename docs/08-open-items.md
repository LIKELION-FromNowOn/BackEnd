# 08 · 아직 정해지지 않은 것

**여기 있는 것은 마음대로 정하지 마십시오.** 지어낸 값이 DB 에 들어가면 되돌리는 데 하루가 갑니다.
막히면 `.agent/REQUESTS.md` 에 적고 그 부분만 건너뜁니다.

## 코드에 직접 걸리는 것

| # | 무엇 | 영향 | 정할 사람 |
|---|---|---|---|
| 1 | **인증 방식** — JWT · 세션 · 매직링크 | `sessions` 테이블 존재 여부. **정해지기 전 `auth/` 착수 불가** | 이철희 |
| 2 | **`daily_logs` 유지 여부** | `actions.completed_at` 파생안이 제안됨. **확정 전 `daily_logs` 만들지 마십시오** | 이철희 |
| 3 | **프롬프트 4종 원문** | `subtract` · `today` · `item` · `coach` 의 AI 호출부 | 송원석 |
| 4 | 관리 항목 최소 개수 | `MIN_ITEMS_REQUIRED` 기준. 제안값 3 | 전원 |
| 5 | 다시 받기 한도 | `actions.reroll_count` 상한 | 이철희 |
| 6 | 상태 전환 재제안 유예 기간 | 예시 3일 | 이철희 |
| 7 | 위기 키워드 목록 | 현재 11개. 확정본 필요 | 김민정 |
| 8 | `CANNOT_REVERT_EXCLUDED` 코드 추가 | 명세서에 아직 없음 (제안) | 송원석 |
