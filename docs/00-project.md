# 00 · 이 프로젝트가 무엇인가

## 한 문단

사람들은 관리 루틴을 **너무 많이 쌓아 두고 지칩니다.** 이 앱은 반대로 갑니다 —
오늘의 컨디션과 클리닉 안내문을 보고 **오늘 하지 않아도 되는 것을 덜어내 줍니다.**
그리고 남은 것 중 **딱 하나**를 「오늘의 행동」으로 제시합니다.

## 사용자가 하는 일 (하루 한 사이클)

```
① 오늘 컨디션 고르기 (5단계)      → POST /checkins
② 앱이 항목별로 판정               → POST /subtract/evaluate
③ 남은 것 중 하나를 행동으로 제시   → GET /today
④ 타이머 → 완료                    → POST /today/start · complete
```

## 차별점 두 가지

| # | 무엇 | 어디서 보이나 |
|---|---|---|
| 1 | **클리닉 안내가 앱 제안보다 우선합니다** | 시술 후 「사우나 5일 남음」이면 그 항목은 판정에서 빠집니다 |
| 2 | **AI 가 지어내지 않습니다** | 케어 코치가 「안내문 4번째 문장에」라고 근거를 가리킵니다. 못 찾으면 모른다고 답합니다 |

## 용어

| 말 | 뜻 |
|---|---|
| **관리 항목** | 사용자가 하기로 한 것. 보습·물 2L·수면 등 32개 마스터 + 직접 입력 |
| **판정 (verdict)** | 오늘 그 항목을 어떻게 할지. `keep` `simplify` `reduce` `skip` `excluded` |
| **floor (하한선)** | 그 항목을 어디까지 내릴 수 있는가. `2` 필수 · `1` 권장 · `0` 선택 · `-1` 판정 제외 |
| **덜어내기 (subtract)** | 판정을 실행하는 것. 이 앱의 심장 |
| **안내문 (care note)** | 클리닉이 준 주의사항. 문장마다 번호가 붙습니다 |
| **규칙 (note rule)** | 안내문 문장에서 뽑아낸 것. `{ sent, dp, kw, item }` |
| **첫 발자국 (footstep)** | 다른 사람이 처음 한 작은 행동 사례 8건 |
| **잠금 (lock)** | 주간 7일 · 월간 30일을 채우면 잠깁니다 |
| **케어 코치 (coach)** | 「사우나 가도 되나요」에 안내문 근거로 답하는 대화 |

## 절대 안 만드는 것

- 연속 달성일 · 달성률 (못 한 날은 기록조차 하지 않습니다)
- 랭킹 · 좋아요 · 키우기
- 성분 설명 (「레티놀이 뭔가요」는 답하지 않습니다. 「오늘 써도 되나요」만 답합니다)
- 브랜드명 · 제품명
