# 06 · 판정 엔진 — `subtract` · `today` · `checkin` 을 만지면 필수

## 판정 값 5종

| 화면 | 코드 | 뜻 |
|---|---|---|
| 그대로 | `keep` | 오늘도 그대로 합니다 |
| 방식만 | `simplify` | 하되 방식을 간단히 |
| 줄이기 | `reduce` | 양·횟수를 줄입니다 |
| 오늘은 쉬기 | `skip` | 오늘은 안 합니다 |
| 판정 안 함 | `excluded` | **앱이 판단하지 않습니다** |

### `excluded` 의 정의 — 오해가 잦은 곳

> **판정 대상에서 제외된 항목.** `floor: -1` 이거나 클리닉 안내문 주의사항에 걸린 항목입니다.
> **화면에서 숨기지 않습니다.** 「건드리지 않은 것」 영역에 사유와 함께 표시하고, **되돌리기 버튼은 띄우지 않습니다.**
> 사유는 `excludedBy` 로 구분 — `floor`(의료 영역) / `clinicNote`(안내문 제한, `noteSent` · `daysLeft` 동봉)

### 되돌리기 가능 여부

| 판정 | 되돌리기 |
|---|---|
| `keep` | 없음 (이미 그대로) |
| `simplify` · `reduce` · `skip` | **있음** → `keep` 으로 고정, 다음 판정에서도 기억 |
| `excluded` | **없음.** 서버도 막습니다 (`CANNOT_REVERT_EXCLUDED`) |

## floor 4등급

| 값 | 뜻 | 최저 판정 |
|---|---|---|
| `2` | 생리적 필수 (보습 · 자외선 차단 · 수면 · 세 끼 · 물) | `simplify` |
| `1` | 권장 | `reduce` |
| `0` | 선택 | `skip` |
| `-1` | **판정 제외** (처방약 · 정기 검진 · 클리닉 안내) | 판정 자체를 안 함 |

## 근거 등급

`0` none · `1` low · `2` medium · `3` high
**`0`(근거 없음)이면 판정하지 않고 `keep` 입니다.**

## 점수

```
load  = base + FQL[frequency]
score = core × 1.7 − load × 0.75 − strict × (load × 0.35)

load ≤ 1.5  →  keep
```

> **계수 1.7 · 0.75 · 0.35 와 임계값은 임의 설계이며 검증 전입니다.** 발표에서 「어떻게 정했나요」를 물으면 그렇게 답합니다.
> **`frequency` 가 없으면 `load` 를 구할 수 없습니다.** 빈도는 반드시 받아야 합니다.

## 처리 순서 8단계 — 순서를 바꾸지 마십시오

```
① 선택 항목만 남김
② floor = -1 제거
③ 클리닉 우선 필터            ← 안내문에 걸린 항목 excluded
④ 근거 등급 0 은 keep
⑤ 되돌린 항목은 keep
⑥ 판정 + 근거 생성            ← AI 는 여기 하나뿐
⑦ 하한선 위반 폐기·되돌림
⑧ 저장
```

**⑥ 전까지는 전부 코드입니다.** AI 에 넘기기 전에 후보를 최대한 줄이십시오.

## 서버 측 검증 8가지 (⑦단계)

| # | 검사 | 걸리면 |
|---|---|---|
| 1 | `floor = -1` 항목에 판정이 있는가 | 제거 |
| 2 | 클리닉 주의사항에 걸린 항목에 판정이 있는가 | `excluded` 로 |
| 3 | `floor = 2` 인데 `reduce` · `skip` 인가 | `simplify` 로 |
| 4 | `floor = 1` 인데 `skip` 인가 | `reduce` 로 |
| 5 | 근거 등급 `0` 인데 판정이 있는가 | `keep` 으로 |
| 6 | 근거 문장에 브랜드명 · 제품명이 있는가 | 사전 문장으로 |
| 7 | 근거 문장에 의학적 단정이 있는가 | 사전 문장으로 |
| 8 | 선택하지 않은 항목이 결과에 있는가 | 제거 |

## 상태 5단계와 여력

| 화면 문구 | 코드 | 여력 |
|---|---|---|
| 아주 좋아요 | `energetic` | 88 |
| 괜찮아요 | `normal` | 70 |
| 좀 처져요 | `low` | 48 |
| 많이 지쳤어요 | `drained` | 26 |
| **잘 모르겠어요** | **`unknown`** | **60** |

**`unknown` 을 빼지 마십시오.** 답을 안 하는 선택지이고, 여력값이 따로 있습니다. **「모르겠다」도 판정을 막지 않습니다.**

## `nextStep` 검사 순서

```
onboarding → rest → checkin → subtract → action → done
             ↑
             추천 중단(rest)이 checkin 보다 먼저입니다
```

「오늘은 아무것도 안 할래요」를 고른 사람에게 상태 점검을 다시 띄우면 안 됩니다.

## 거절 사유 3종

| 값 | 처리 |
|---|---|
| `time` | 더 짧은 것으로 다시 고름 |
| `fit` | 오늘 후보에서 제외 |
| `none` | **제안 중단. 실패로 기록하지 않음.** 첫 발자국 카드도 내림 |

## 안내문 규칙

```
규칙 = { sent, dp, name, kw, item }
daysLeft = max(0, dp − 시술 후 경과일)
```

- **`daysLeft` 를 저장하지 않습니다.** 읽을 때마다 계산합니다. 저장하면 날짜가 지나도 안 줄어듭니다
- **여러 규칙에 걸리면 `dp` 가 가장 큰 것**을 돌려줍니다. 먼저 풀리는 걸 보여 주면 틀린 안내가 됩니다
