# 01 · 확정된 결정과 그 근거

**「왜 이렇게 되어 있지?」 싶을 때 여기를 먼저 보십시오.**
근거 없이 바꾸면 이미 결정을 내린 이유가 사라집니다.

| 날짜 | 결정 | 왜 |
|---|---|---|
| 8/11 | **첫 발자국은 탭이 아니라 카드** | 탭을 하나 줄이면서도, 매일 여는 홈에 있으면 오히려 더 읽힙니다 |
| 8/11 | **첫 발자국 상세 API 를 만들지 않음** | 사례가 8건뿐이라 목록에 통째로 담는 편이 호출이 적습니다 |
| 8/11 | 판정 4종 → **5종** (`excluded` 신설) | 의료·클리닉 항목은 「쉬는 것」과 뜻이 다릅니다 |
| 8/11 | 판정 7단계 → **8단계** (③ 클리닉 우선 삽입) | 클리닉 안내가 앱 제안보다 우선한다는 원칙의 구현 자리 |
| 8/11 | 서버 검증 7 → **8가지** | 위와 같은 이유 |
| 8/11 | 홈 배치 — **관리 맥락 카드가 맨 위** | 차별점을 첫 화면 첫 줄에서 보여주려는 것 |
| 8/12 | **매니페스트를 쓰지 않음** | 대신 정보구조도 · DB 설계서 · 시스템 아키텍처 세 문서로 대체 |
| 8/13 | **React 로 확정** | 프로토타입의 CSS · 데이터 · 판정 엔진을 그대로 옮길 수 있습니다 |
| 8/13 | **목 API 레이어 유지** | `live.ts` 플래그로 API 단위 전환. 서버가 늦어도 데모가 삽니다 |
| 8/14 | **`excluded` 이름 유지 + 정의 명시** | 이름이 다섯 곳에 박혀 있고 `excludedBy` 와 짝입니다. 동결 6일 전에 바꿀 자리가 아닙니다 |
| 8/14 | **기능(도메인)별 패키지** | 계층별이면 셋이 매일 같은 세 폴더를 건드립니다 |
| 8/14 | **`AuthUser` 대신 사용자 번호만** | `@ManyToOne` 을 쓰면 14개 패키지가 한 덩어리가 됩니다 |
| **8/18** | **사용자 번호 타입은 `Long` 이 아니라 `String`** | ID 가 「접두어 + ULID」(`us_01H8X…`)이고 `schema_v63.sql` 이 PK·FK 를 전부 `text` 로 정의했습니다. **`Long` 은 선택지가 아닙니다** |
| 8/14 | **클래스 이름에 패키지 접두어** | 같은 단순명이 둘이면 스프링 부팅이 실패합니다 |
| 8/14 | **`PATCH /me` 를 `auth/` 로 통합** | `users` 테이블을 두 사람이 쓰고 있었습니다 |
| 8/14 | **역할을 건수가 아니라 작업량으로 분배** | 건수 30% 를 뺐더니 시간으로는 23% 였습니다 |
| 8/14 | **브랜치 `main` · `develop` · `feature/*`** | `master` 는 쓰지 않습니다 |
| 8/14 | **응답 다이어트 규칙 대부분 완화** | API JSON 은 2MB 예산의 0.5%. 진짜 위험은 웹폰트였습니다 |
| 8/14 | **AI 호출은 네 곳** | 판정 근거 · 오늘의 행동 · 직접 입력 해석 · 케어 코치 |

## 판정 값 코드명 — 8/14 확정

`keep` / `simplify` / `reduce` / `skip` / `excluded`

프로토타입의 짧은 이름(`simp` `red` `drop` `lock`)은 **내부 값**이고,
서버는 처음부터 명세서 이름을 씁니다. 프론트의 `mapper.ts` 가 목 API 경로에서만 변환합니다.

## 일부러 만들지 않기로 한 것

| 무엇 | 왜 |
|---|---|
| 연속 달성일 · 달성률 | 못 한 날을 실패로 만들지 않는 것이 제품 원칙입니다 |
| 랭킹 · 좋아요 · 키우기 | 잠금(주 7일 · 월 30일)으로 대신합니다 |
| 성분 설명 | 「레티놀이 뭔가요」는 전문성 대결이 됩니다. 「오늘 써도 되나요」만 답합니다 |
| 게스트 전용 테이블 | 게스트도 `users` 에 넣습니다. 회원 전환 때 옮길 일이 없어집니다 |
| 위기 신호 원문 저장 | 해시와 걸린 키워드만 남깁니다 |
| 첫 발자국 상세 테이블 | 8건뿐입니다 |

## 인용하면 안 되는 것

- **사용자 인터뷰 0건.** 모든 문제 정의는 가설입니다
- 판정 계수 · 임계값은 **임의 설계이며 검증 전**입니다
- **안내문 원문 6문장과 규칙 5개는 실제 클리닉 문서가 아닌 가상 샘플**입니다
- 성분 지식 13종은 전문가 검수 전입니다
- 첫 발자국 8건 · 짚어주기 90케이스는 **작성한 시나리오**입니다
