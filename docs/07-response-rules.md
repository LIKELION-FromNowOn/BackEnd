# 07 · 응답 설계 규칙

## 봉투

```json
성공  { "ok": true,  "data": { ... } }
실패  { "ok": false, "error": { "code": "MIN_ITEMS_REQUIRED", "message": "..." } }
```

**엔티티를 그대로 직렬화하지 않습니다.** `created_at` `updated_at` 같은 게 따라 나가고, 컬럼을 추가할 때마다 응답이 조용히 뚱뚱해집니다.

## 트래픽 전제

팀 목표는 **프론트·디자인 포함 2MB** 입니다. 재 보니 **API JSON 은 하루 10.5KB 로 예산의 0.5%** 였습니다.
**진짜 위험은 한글 웹폰트(서브셋 안 하면 600KB~2MB)** 이고, 그건 프론트 몫입니다.

그래서 **바이트를 아끼는 규칙은 대부분 폐기했습니다.** 남긴 것은 바이트가 아니라 **요청 수 · 쿼리 안정성 · 서버 부하** 때문입니다.

## 지키는 규칙 넷

| # | 규칙 | 진짜 이유 |
|---|---|---|
| 1 | **마스터 4종에 캐시 헤더** — `Cache-Control: public, max-age=3600` + `ETag` (동결 후 `86400`) | 요청 수를 줄입니다. 설정 5분 |
| 2 | **목록에 기간·개수 제한** — `GET /logs` 기본 14일 최대 90일 · `GET /me/plans` 30건 | 쿼리 안정성. 오래 쓴 사용자일수록 느려집니다 |
| 3 | **폴링 금지** — 타이머는 클라이언트에서 | 15분 타이머를 1초마다 확인하면 요청 900개입니다 |
| 4 | **N+1 금지** — 홈은 다섯 조각을 각각 쿼리 1회 이내 | 응답 속도 |

## 폐기한 규칙

**「이름 대신 id 만 보내기」는 폐기했습니다.** 아끼는 것이 2KB 인데, 직접 입력 항목 예외 분기 · 모르는 id 면 이름이 빈칸 · 디버깅 난이도를 감수해야 합니다. **이름을 같이 보냅니다.**

## `GET /home` — 요약 위주로

목록을 통째로 담지 않습니다. 다만 **아래 네 가지는 일부러 남깁니다.**

| 남긴 것 | 왜 |
|---|---|
| 살아 있는 주의사항 **2건** (`topRules`) | 「사우나 5일 남음」이 차별점을 첫 화면에서 보여줍니다 |
| 판정 결과의 **근거 문장** | 없으면 「왜 줄이라는 건지」를 알 수 없습니다 |
| 코치 답변의 **인용 문장 원문** | 대화 안에서 바로 근거가 보여야 합니다 |
| 마이 화면 **호출 3회** | 합치면 마이를 안 쓰는 사용자가 손해입니다 |

```json
{
  "ok": true,
  "data": {
    "nextStep": "checkin",
    "care": {
      "procedure": "레이저 토닝", "daysAgo": 2, "activeRuleCount": 3,
      "topRules": [
        { "sent": 4, "name": "사우나 · 찜질", "daysLeft": 5 },
        { "sent": 2, "name": "강한 각질 제거", "daysLeft": 3 }
      ]
    },
    "state": { "value": "low", "checkedAt": "2026-08-14T09:12:00+09:00" },
    "subtract": { "keep": 5, "simplify": 2, "reduce": 1, "skip": 0, "excluded": 3 },
    "today": { "actionId": 8812, "itemId": "cr4", "durationSec": 420, "status": "pending" },
    "footstepId": "fs3"
  }
}
```

`topRules` 가 셋 이상이면 **`daysLeft` 가 큰 순으로 두 개만** 보내고 나머지는 개수로 표시합니다.

## 그 밖에

| 항목 | 내용 |
|---|---|
| 응답 압축 | `server.compression.enabled=true` — 한 줄이면 됩니다 |
| **판정은 하루 한 번** | `POST /subtract/evaluate` 는 그날 결과가 있으면 재실행하지 않습니다. **AI 호출 비용이 여기 걸립니다** |
| 날짜 | ISO-8601 · `+09:00` |
